# Installation notes:
# 1. First install HiRAG: pip install -e .
# 2. Then install PDF dependencies: pip install -r pdf_requirements.txt
# 3. For OCR support, also install tesseract system package:
#    - Ubuntu/Debian: sudo apt-get install tesseract-ocr
#    - macOS: brew install tesseract
#    - Windows: Download from https://github.com/UB-Mannheim/tesseract/wiki
#
# Note about textract:
# The textract package has metadata compatibility issues with pip >= 24.1
# If you need textract functionality, you can either:
# - Downgrade pip: pip install "pip<24.1" && pip install textract==1.6.5
# - Use alternative packages like python-docx, openpyxl, and python-magic
# - Install textract directly: pip install --no-deps textract==1.6.5 (may have dependency issues)
